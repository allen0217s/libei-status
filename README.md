# 男主状态 · 独立状态面板

SillyTavern 前端扩展，按角色、聊天和回复分支保存状态。提供「当前状态」「变量规则」「上下文」「设置」四页，不依赖 MVU、Tavern Helper 或外部数据库。

## 功能与本轮简化

| 功能 | 当前范围 |
| --- | --- |
| 当前状态 | 字段分组显示、手动维护、楼层历史、重新计算和状态存档 |
| 变量字段 | 名称、分组、类型、默认值、更新规则、复制、排序、停用与显示开关；最多 128 项 |
| 变量预设 | 默认、黎北及最多 50 个自建预设；保存字段定义、字段更新规则及最多 20 套初值方案 |
| 预设导出 | 在插件页面生成纯文本，点击复制；不下载文件 |
| 预设导入 | 在同一文本框粘贴规定格式，解析后载入字段草稿 |
| 角色配置 | 主角称呼置于变量规则页顶部；通用规则、提示词、世界书引用和计算参数不随预设传递 |
| 上下文 | 独立页面编辑任务说明、通用规则、引用与参数；显示发送对象、只读边界及分段字符数 |
| 状态更新 | 跟随主 API，或显式选择独立副渠道；支持当前角色绑定的世界书条目引用 |
| 界面 | 五套主题、桌面与手机布局；可选择书签、顶栏、输入框及楼层入口 |

已删除预设的文件选择、JSON 文件下载和旧整包 JSON 解析分支，去掉重复说明与过时界面图片。状态历史、旧数据兼容、来源声明和历史验证报告保留。旧规则 JSON **不能粘贴到新的字段预设入口**；原浏览器内的自建预设读取字段与已保存的初值；此前只有字段的预设将显示零套初值，可在页面新增。聊天状态存档继续使用原格式。

## 安装与首次使用

1. 更新前导出完整状态存档、备份酒馆设置，并停用角色卡内旧状态脚本。
2. 在酒馆「扩展 → 安装扩展」填写 `https://github.com/allen0217s/libei-status`。已安装用户在扩展管理中更新后刷新页面。此版本仍为预览版，验证范围见下文。
3. 在魔杖菜单打开「男主状态」，进入要跟踪的单角色聊天；暂不支持群聊。
4. 在「设置」明确选择主 API 或副渠道；旧 API 配置只会经显式确认导入，不会自动上传旧密钥。
5. 在「变量规则」最上方填写主角称呼，然后载入变量预设。可选择一套初值方案，也可选择“无初值”；不根据角色名或开场猜测初值。

建议 SillyTavern 1.19.0+，使用 localhost 或 HTTPS。写入依赖 Web Locks，普通局域网 HTTP 可能只读。手动安装时保持根目录的 `manifest.json`、`index.js`、`index.css`；用户无需安装 Node 或构建。CSS 由插件载入 Shadow DOM。

## 变量预设与初值：复制与粘贴

在「变量规则 → 变量预设」操作：

1. **载入预设草稿**：载入该预设的字段与初值方案，保留其他配置。初值选择默认重置为“无初值”，可在同一区域选择一套方案、编辑或新建初值。
2. **生成导出文本**：把当前字段与初值方案草稿写入页面文本框。点击「复制文本」；若浏览器拒绝剪贴板权限，会选中文本供手动复制。
3. **解析导入草稿**：先粘贴文本，再点击解析。失败保留原草稿和粘贴文本；成功仍未保存。
4. **保存规则 → 确认应用此预设**：选择了初值就直接用该方案建立当前状态，不请求模型；选择“无初值”则当前状态留空、注入暂停，可再到「当前状态」按剧情手动生成。两种方式均保留旧快照，不继承旧状态。
5. **另存为预设**：保存字段与初值方案的副本，不应用到聊天，内置预设不可删除。导出与另存不携带当前初值选择，载入后始终由你选择。

预设包含名称、字段定义及多套初值方案。每套初值用 `id`、`label`、`text` 表示，`text` 是 YAML / JSON 初值文本；默认、黎北预设分别带自己的初值。选择“无初值”不会使用第一套方案，也不会用字段默认值自动创建状态。全局提示词、世界书引用、计算参数、聊天进度和 API 配置均不随预设导出；使用黎北初值也不会自动改变生理计算参数。

格式为 UTF-8 纯文本：第一行固定为 `# 男主状态变量预设 v2`，其后是 YAML，仅接受「名称」「字段」「初值方案」三个顶层键。旧 v1 字段文本仍可导入，按零套初值处理。下面是可导入的最小示例；其他字段可先用页面导出作模板。

```yaml
# 男主状态变量预设 v2
名称: 日常示例
字段:
  - id: world-date
    path: [世界, 日期]
    label: 日期
    group: 世界
    type: string
    default: 第1天
    enabled: true
    visible: true
    updateMode: ai
    system: date
    rule: 只按正文明确的日期更新。
  - id: world-time
    path: [世界, 时间]
    label: 时间
    group: 世界
    type: string
    default: "00:00"
    enabled: true
    visible: true
    updateMode: ai
    system: time
    rule: 使用 HH:MM，只按正文实际经过的时间更新。
初值方案: []
```

零套初值填写 `初值方案: []`；新增时可在页面按字段默认值创建方案。使用空格缩进；多行规则可用 `rule: |` 后换行缩进。日期和时间必须保留，ID 与路径不能重复；不接受锚点、别名、自定义标签或额外配置。文本最多 250000 字符。类型支持 `string/integer/number/boolean/enum/array/object`，更新方式为 `ai/manual/program`，`program` 仅限原有系统计算字段。

## 上下文与错误诊断

变量规则和上下文是独立导航页：切页保留未保存草稿，保存或放弃只作用于当前页；换角色时丢弃旧角色草稿。主角称呼位于变量规则页顶部，预设与初值位于其下。

上下文页集中维护任务说明、通用规则、世界书引用、计算参数、输出协议、正文状态模板与正文职责。预览复用实际请求组装函数，展示插件更新与正文注入的各段内容、维护位置、只读边界和字符数；字符数不等于 token 或费用。程序固定保护、状态和消息资料保持只读。

补丁仍使用原有 `op/path/value` 及数值事件格式。失败时红字标明可定位的操作序号、字段路径和类型要求；「本次更新明细」记录本轮拒绝原因。混合事件与普通操作时仍按模型原始数组编号。整轮拒绝、不写一半、不自动修复或新增请求。例如：第 2 条操作试图直接改钱财，会提示改用 `money` 收支事件。

## 数据与运行边界

- 状态与角色规则保存在当前浏览器 localStorage；自建预设不自动跨设备同步。渠道、主题、入口与排除名单保存到 `extensionSettings.libei_status_v2`，可能随酒馆账户同步。
- 渠道密钥在完成编辑后**明文存入酒馆设置**，不是 secrets 加密存储。测试或拉模型会经酒馆发给指定服务；关闭渠道弹窗丢弃草稿。状态存档和变量预设不导出 API 密钥。
- 修改字段不批量改写旧快照；停用字段保留原始值。历史楼层使用自身的字段定义。不兼容类型会阻止保存或更新，不能靠预设静默转换旧值。
- 初值必须通过所属字段的类型检查；缺少的启用字段按默认值补齐。无初值仅代表不选择方案，不会跳过后续生成校验。默认现代钱财以人民币整元记账；其他计量单位需另行约定。
- 世界书引用只保存当前角色绑定书的书名/UID，发送前重新读取，不执行宏或 EJS；缺失、排除、换绑或请求期间改变会停止请求或丢弃结果。
- 切换角色/聊天、取消或修改配置会丢弃过期结果。主 API 沿用 `generateRaw`，无法保证停止宿主请求或观测截断原因；副 API 支持网络取消并拒绝 `length` 截断。

字段、提示词、旧数据与程序结算的详细约定见 [状态维护协议](docs/STATE_PROTOCOL.md)。角色改名不影响头像标识分区；更换头像标识视为新角色。多标签页不能同时写入。

## 开发与验证

运行资源在根目录，维护源码在 `src/`；构建后自动同步根目录 JS/CSS。不要直接修改打包文件。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm run typecheck
pnpm run build
pnpm test
pnpm run test:rules
pnpm run test:fields
pnpm run test:references
pnpm run test:presets
pnpm run test:context
```

浏览器检查需要 Chromium，可用 `LIBEI_BROWSER_PATH` 指定路径。使用隔离 profile、内存数据和模拟 API，不连接真实酒馆或供应商。历史脚本 `pnpm run test:browser` 的初始状态断言与当前 fixture 不一致，仍不计入通过项；未因本轮改动删去它的渠道界面覆盖。

2026-10-26 本地验证：类型检查、构建、143 项模块检查与 87 项隔离浏览器检查通过；其中上下文检查覆盖独立保存、跨页草稿保留、拒绝更新无部分写入且无自动修复；预设检查覆盖多套初值、无初值、所选初值直接应用、旧 v1 文本兼容、页面复制/粘贴和剪贴板回退。**真实酒馆安装、资源加载、持久化与真实 API 仍待验收。** 构建仍有宿主脚本/CSS 运行时 URL 警告；manifest 校验仍提示 Extras 字段弃用。`validation/` 是历史报告，不能代替当前运行结果。
