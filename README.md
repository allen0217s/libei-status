# 黎北状态 · 通用状态引擎

SillyTavern 前端扩展。一份 JSON / YAML 状态示例，加上简短更新指令，就能为不同角色卡生成状态，并在悬浮入口打开的独立面板中查看。当前版本：**3.0.0-preview.1**。

## 使用

1. 在单角色聊天中打开“通用状态”。
2. 在“当前状态”选择万用通用、日常恋爱、RPG 冒险、修仙历程，或在“状态预设”保存自己的模板。
3. 在“设置 → 状态生成方式”选择生成模式：
   - **随正文生成**：在正常回复末尾附带状态块，插件自动提取并隐藏其显示。共用正文请求，状态仍消耗上下文和输出 token。
   - **独立请求生成**：正文完成后另外请求一次状态；可跟随酒馆当前主 API，也可指定副渠道。默认参考最近 3 条消息和旧状态；不读取世界书。
4. 新聊天不会把模板示例冒充真实初值。继续聊天生成状态，或明确点击“以模板内容手动初始化”。

生成模式、预设库、渠道和界面偏好保存在酒馆扩展设置中。**当前预设与状态随聊天保存**，切换角色或聊天时自动切换。群聊暂不在处理范围内。

## 模板与复制粘贴

在“状态预设”编辑状态示例与更新指令，无需逐个建立字段。支持页面文本框导出、复制、粘贴导入；导入先成为草稿，应用后才生效。

可粘贴的预设示例：

```yaml
名称: 日常示例
模板:
  场景:
    时间: 未记录
    地点: 未记录
  角色:
    好感度: null
    心情: 未记录
    衣着: []
    想法: 未记录
更新指令: |
  依据已发生的剧情维护状态，不替玩家决定行动。
  好感度使用 0–100；没有依据时保留 null。
  衣着只记录当前穿着，想法只写被跟踪角色的想法。
```

预设只含名称、模板和更新指令，不携带渠道、密钥或聊天记录。内置预设可以另存修改。切换或重新应用预设会开始新的状态记录，旧快照仍可从历史选择器查看。

## 状态面板

- 数值比例和百分比显示为进度条；HP 等数值可读取同级“HP上限”“最大HP”“HP_max”。
- 常见评分字段没有上限且数值在 0–100 时，按 100 分约定显示，并提供提示；其他数字照常显示。
- 简单数组显示为标签；对象和复杂数组递归显示，第二层及更深对象默认折叠。
- 数值变化显示 +5 / -5 等徽章，支持减少动画偏好。
- 可查看历史快照、原始数据，或手动编辑 JSON / YAML。
- 保留悬浮入口、顶栏、输入框与楼层入口，以及五套主题和移动端抽屉。

状态块隐藏仅改变显示，不修改聊天原文、swipe 内容、角色卡或宿主正则设置。不完整或无效的状态块保留显示并报错。宿主没有消息格式化接口时，状态块保持可见。

## 升级与旧数据

本次已移除世界书读取与选择页、逐字段 GUI、专用衣着/数值结算及旧适配引擎。统一使用通用状态协议，旧程序字段的计算和写入权限不再执行。

**升级前先导出旧版完整存档。** 新版提供两条明确的迁移入口：

- “设置 → 存档与存储管理 → 复制旧版当前状态”：核对当前角色、聊天、回复分支后，仅复制旧版当前状态，并建立可编辑的模板。原浏览器存档和全部旧快照保持原样。
- “状态预设 → 复制与粘贴预设 → 转换旧版完整字段草稿”：明确勾选说明后，把旧字段默认值与文字规则转换为模板。字段权限、开关、显示筛选、多套初值、程序结算和世界书引用不迁入，需检查新的更新指令。

旧版 API 密钥仍只经显式导入草稿后保存；不会随状态迁移上传。新存档可导出/导入，导入会核对角色和聊天。新版最多保留最近 80 次快照、400 万字符；可导出后选择“仅保留当前快照”。

本地重构前的未提交源码与测试已备份到 `_backups/universal-status-20261027-172424/`。旧版说明归档在 [2.x 文档](docs/archive-v2/README.md)；原有测试文件与历史报告保留，不能视为新版已通过的检查。

## 运行与验证

酒馆从仓库根目录加载 `manifest.json`、`index.js`、`index.css`。源码在 `src/`，构建会同步根目录资源；不要手动编辑打包文件。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm run typecheck
pnpm test
pnpm run build
pnpm run test:browser
```

浏览器检查使用隔离配置、模拟聊天、模拟持久化和模拟 API，不连接真实服务。可用 `LIBEI_BROWSER_PATH` 指定 Chromium。

2026-10-27 本地验证：类型检查与构建通过；57 项新引擎/API 检查、25 项隔离浏览器检查通过。报告在 [validation](validation/)。真实酒馆的安装、服务端保存、流式事件顺序、扩展互相影响及真实模型输出仍待验收。建议使用具备能力检查所列接口的 SillyTavern 1.19.0+；不依赖 Tavern Helper、MVU、运行时 CDN 或外部数据库。

主 API 的 generateRaw 只返回文本，取消会丢弃结果，无法保证中止宿主请求或检测所有截断。副渠道支持网络取消，并拒绝显式的 length 截断。副渠道密钥以明文保存在酒馆账户设置中。通过 Web Locks 保持同一浏览器来源仅一个页面可写；其他页面仅查看。普通局域网 HTTP 缺少该能力时仅可查看，请使用 localhost 或 HTTPS。锁不跨设备协调。

协议与实现说明：[状态协议](docs/STATE_PROTOCOL.md)、[架构与接口依据](docs/UNIVERSAL_ENGINE.md)。
