# 状态维护协议

本文说明现有状态引擎的约定；变量预设传递字段定义及其初值方案，不覆盖这里的程序行为。

## 字段和旧数据

状态以「世界 / 主角」分区；旧「黎北」分区兼容读取。每个字段的 ID 与路径固定，修改显示名不会搬移数据。启用、显示和发送给正文分别控制维护、面板和正文状态投影；停用项不进入活动提示词，但原始值保留。列表与对象只检查容器和 JSON 安全性，不逐子项声明结构。

普通字段保存时自动校验并补齐缺失初值，并同步仍等于旧默认值的初值；单独设置过的值保留。查看旧楼层用该节点自己的定义，不补写历史。当前内存视图的缺值补全，直到正常结算或显式手动写入时才随新快照保存。不兼容旧值会阻止更新，不截断或静默清空。末楼重算保留当前手动字段、停用字段，以前楼为数值结算基准。

旧规则无字段定义时从初值推导；无法统一的字段保留原值，记录在 `fieldSchemaNotes`。旧内衬与遮露归档；内衬不推定为内裤。上装、下装和旧鞋履路径/ID 保留，鞋履显示为鞋袜；缺少内裤先显示未记录。原字段规则按路径拆分一次，原文保存在 `fieldRuleSource`，跨字段与无法匹配的内容留在通用规则。

## 模型请求与正文注入

更新请求的 system 消息包含任务、跟踪对象、字段定义及规则、通用规则、引用标识、计算参数、输出协议和固定保护。user 消息是资料 JSON：`target_message_id` 为唯一结算目标，`previous_state` 为前一状态，`current_turn` 为上次结算后的本轮消息，`recent_messages` 仅供理解，不重复结算。选定世界书原文可前置；不复制正文模型的完整预设、人设与所有历史。

上下文独立于变量规则页面；两页共享配置读取，但分别保存或放弃各自草稿，切页保留未保存编辑，换角色时清理旧草稿。请求预览与实际发送共用组装函数；预览不发送模型请求或保存草稿。收集世界书参考需显式操作。正文预览仅代表本插件注入段，不是酒馆最终整包请求。

结算后重新注册状态注入，供下一次正文使用，不追溯修改已有正文。正文收到跟踪对象、勾选字段的当前状态、单独填写的正文叙事约束和正文职责，不收到完整字段维护规则、类型/写入权限或插件专用输出协议。引用只用于变量更新，不改酒馆正文原有世界书机制。

变量预设载入后默认选择“无初值”。点击保存时，若已手动选择初值方案，则将其校验后的状态作为新节点直接写入当前楼层，保留旧节点，不请求模型；若选择“无初值”，则当前状态留空，自动更新与注入暂停。手动重新生成使用 `previous_state:null`，不发旧状态，返回完整字段值并整体校验。手动字段使用所选初值或字段默认值；非零程序余额需当前剧情引文。失败保持留空，旧快照不变。

## 更新协议与计算

- 更新模型输出一个 JSON 数组，普通字段用 `add/replace/remove`；路径相对于状态对象。旧标签输入仍可解析，但不能绕过写入限制。此协议还包含事件，不是完整 RFC 6902。
- 收支事件：`{"op":"money","direction":"income","amount":整数金额,"evidence":"本轮连续引文"}`，方向为 `income/expense`。
- 消耗事件：`{"op":"release","kind":"awake","amount":单次消耗量,"count":实际次数,"evidence":"本轮连续引文"}`，类型为 `ejaculation/awake/dream`；count 可省略，默认为 1。
- 钱财、精液、精液算式由程序写入，模型不能替换其父对象。任一事件无效时整轮拒绝；引文匹配不保证模型事实判断一定正确。
- 增长按本轮整小时 × `hourlyGain`，不足一小时不跨轮累计。普通消耗默认 10～20、梦遗 20～40，是游戏参数，不是医学标准；程序不会因阈值凭空生成事件。
- 支持「第 N 天」及同月中文月日。跨月/年必须明确公历年份；缺少年份、自定义历法或时间倒退时拒绝猜测。

计算只读取 `numericConfig`，自然语言字段规则和世界书不能改变公式。新角色默认：

```json
{"version":1,"hourlyGain":0,"normalMin":10,"normalMax":20,"dreamMin":20,"dreamMax":40,"moneyMax":1000000000000}
```

旧配置缺少 `moneyMax` 时仍用旧上限 100000。切换变量预设不修改这些参数；需在「程序计算参数」中显式编辑。

旧输出/原版更新规则分别归档到 `legacyOutputFormat/legacyUpdateRules`，不删除初值、进度或未知状态值。新节点保存 `settlement` 依据，旧快照不追溯重算。

## 耗时与更新明细

耗时统计范围为状态请求开始至输出接收或失败，包含请求所需资料读取及网络等待，不代表供应商内部推理耗时。运行中实时显示，完成后显示耗时及本地完成时刻。模型 API 连接测试不计入状态输出耗时。

当前更新明细显示字段前后差异，保留原有操作和结算数据；初始化显示生成后的字段值。新节点仅额外保存请求耗时，不复制整份报告；重读历史时使用节点及父节点恢复字段差异。无变化显示明确提示，失败记录拒绝原因。

保存规则保留内部预校验与版本检查，并在一次点击中完成提交，不显示二次确认。自动更新开关和参考消息数移至设置页，全局行为保持不变。

## 校验拒绝

普通路径补丁、数值事件和原始回复格式保持不变。可定位的校验失败会附带原始数组操作序号与字段路径；字段类型/范围失败显示要求及收到的值。混合事件与普通字段时不会按过滤后的子数组错编号。

状态计算仍在副本中完成，校验全部通过且角色、聊天、分支与存储版本未变化时才提交。失败记录拒绝摘要供界面查看，不保存整个原始模型回复，不自动调用模型修复。
